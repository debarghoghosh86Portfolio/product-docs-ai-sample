# Projects and tasks

## Create a task

Press `N` anywhere in a project, or click **+ Add task** at the bottom of a board column. A task needs a title; everything else is optional: description, assignee, due date, priority (Low, Medium, High, Urgent), and labels.

## Subtasks and dependencies

Break large tasks into subtasks from the task's **Subtasks** section. Subtasks can be nested up to 3 levels deep.

To mark that one task must finish before another can start, open the task and choose **Add dependency > Blocked by**. A blocked task shows a red lock icon on the board and cannot be moved to the *Done* column until all blocking tasks are done.

## Recurring tasks

Set a task to repeat daily, weekly, monthly, or on custom days from **Due date > Repeat**. A new copy is created when the current one is marked done.

## Board views

Every project can be viewed as a **Board** (Kanban columns), **List**, **Calendar**, or **Timeline** (Gantt). Timeline view is available on the Pro and Business plans.

## Archive and delete

Archiving a project hides it from the sidebar but keeps all data; you can restore it any time from **Settings > Archived projects**.

Deleted tasks go to the project **Trash** and are permanently removed after 30 days. Only admins and owners can delete whole projects, and a deleted project cannot be restored.

## Limits

- Free plan: up to 5 projects and 10 members.
- File attachments: up to 100 MB per file on Free, 1 GB per file on Pro and Business.
